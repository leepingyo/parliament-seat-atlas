# 議席圖譜

以法國國民議會的半圓議場為視覺參考。每個圓點代表一席，點選政黨或席位可查看占比。座席位置為視覺化分區。

## 國家選單

依 [V-Dem Democracy Report 2026 表1](https://www.v-dem.net/documents/75/V-Dem_Institute_Democracy_Report_2026_lowres.pdf) 的 Regimes of the World 主要分類，列出87個自由民主或選舉民主國家。分類資料評估2025年，包含有不確定性標記的民主國家。

## 嵌入文章

1. 選擇國家。若要自訂，點「編輯席次」調整後按「套用預覽」。
2. 點「取得嵌入碼」。
3. 選擇「固定目前席次與配色」或「隨公開網站更新」，再按「複製嵌入碼」。
4. 貼入文章編輯器的 HTML／嵌入區塊，依文章預覽調整圖框高度。

固定快照將目前的席次、政黨名稱及配色寫入 iframe 網址的片段，文章載入時可重現該圖。隨公開網站更新會讀取該國已發布資料。嵌入版面隱藏網站編輯工具與國家選單，寬度自動配合文章欄位。文章平台需允許 iframe。

## 更新公開資料

套用預覽後下載席次 JSON，使用具有寫入權限的 GitHub 帳號將檔案上傳至 `main` 根目錄並提交。保留檔名，例如 `seats-JP.json`。GitHub Pages 完成部署後即可更新。

網站優先讀取已發布的各國 JSON，尚無檔案時使用十一國預載快照，其餘國家可自行建立。
